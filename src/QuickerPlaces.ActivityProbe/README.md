# Phase 9 developer probe (20–30 minutes)

1. Open `src/QuickerPlaces.sln` in Visual Studio. Set **QuickerPlaces.ActivityProbe** as the startup project and press **Ctrl+F5**. Confirm it says `Debugger attached: False`.
2. Open five separate File Explorer windows (Ctrl+N opens a window; Ctrl+T opens a tab). Choose **1 Live view**. Navigate to a different folder, open and close a window, and switch between windows. The foreground entry should have `*`; paths and the entry count should update within a few seconds. `navigationEvents` should rise on navigation and `windowEvents` on opening or closing a window. If either count fails to rise, stop here and send the console result; the event hookup needs correction before another stress run. Press **2** to go straight to Stress, **3** for Host, or **Q** to return to the menu. Paths appear only on screen.
3. Leave the five windows open and choose **2 Stress**. The tool initializes its event cache and reports both entry count and distinct HWND count (five separate windows should have five distinct HWNDs) before timing 20,000 rapid cached samples. The console and log report pass times, reconciliation time, and sample Explorer handle totals and process private bytes every 1,000 passes after garbage collection.
4. Choose **3 Host/lock run**. The console reports progress about every 15 seconds while the host wakes. Press **Win+L** for about one minute, then unlock; it should report zero timer wakes during the lock. Press **Enter** in the console to stop the host and see the shutdown time.
5. Choose **1 Live view** again. While it is running, right-click **Windows Explorer** in Task Manager and choose **Restart** (closing and reopening a folder window does not restart the Explorer process). Open a folder window afterwards. Allow up to 90 seconds for the one-minute reconciliation and retry. The old entries should disappear and new entries should appear, with a new HWND or higher event/reconciliation counts. Send the console lines around that transition.
6. Choose **Q**. Send the single `activity-probe.log` path printed at startup. The temporary `activity.json` store is deleted when the tool exits. The log contains counts, timings, signals and error classes; observed folder paths are never written to it.

The mapped-drive equivalence check is a separate ten-minute run on the work computer, after the Activity window can configure a root.
